🚀 快速开始

1

克隆仓库

将模板克隆到本地（或直接下载 ZIP）。

2

编辑个人信息

打开 cv-content-zh.tex（中文）或 cv-content-en.tex（英文），按注释替换示例内容（张大山 / Da-Shan Zhang）。

3

替换照片

将你的证件照放入 resources/photo.jpg。

4

一键换肤（可选）

在 academic-cv.sty 的配色区块修改 4 个 RGB 值，即可切换整体主题色。

5

编译生成 PDF

需要 TeX Live 2024+，运行下方命令即可。

# 中文版（需运行两次，确保页眉/页脚定位正确）
$ xelatex main-zh.tex
$ xelatex main-zh.tex
✔ main-zh.pdf

# 英文版
$ xelatex main-en.tex
$ xelatex main-en.tex
✔ main-en.pdf

# 或使用 Makefile 一键编译
$ make    # 同时编译中英文
$ make zh  # 仅中文
$ make en  # 仅英文

├── Makefile              # 一键编译（en / zh / all / clean）

├── LICENSE                # MIT 许可证
└── README.md / README-zh.md
